# Пример поиска динамики роботов

В [ноутбуке](robot_reference.ipynb) показано, как искать уравнения по реальной записи движения роботов в слабой постановке EPDE. Поиск идёт на первых 60 секундах записи, проверка — на следующей минуте. Для чтения достаточно сохранённых графиков и таблиц.

## Установка и запуск

Понадобятся Git и Python 3.12. Клон EPDE вместе с данными занимает около 550 МБ, зависимости включают PyTorch.

Скачайте репозиторий целиком и откройте терминал в его корне. Контрольный запуск выполнен на macOS ARM.

На macOS или Linux создайте и активируйте окружение:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

На Windows в командной строке cmd:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate.bat
```

Далее на любой системе выполните:

```bash
python -m pip install -r requirements.txt
git clone --branch domain_refactor https://github.com/ITMO-NSS-team/EPDE.git vendor/EPDE
git -C vendor/EPDE checkout 48e3789aedb9a316b9a5cee78e0c8f96e9f196ba
jupyter execute --inplace cases/robots/robot_reference.ipynb
```

Коммит закреплён, чтобы пример запускался на той версии, на которой он проверен. Весь код примера находится в самом ноутбуке. Последняя команда выполняет его на сохранённых результатах поиска и записывает выводы в него же, это занимает меньше минуты. На macOS ARM с Python 3.12 для точного воспроизведения окружения можно установить `requirements-lock-macos-py312.txt` вместо `requirements.txt`.

Чтобы заново выполнить все 120 поисков EPDE, задайте переменную окружения `ROBOTS_RERUN=1`. В восемь параллельных процессов на macOS ARM это заняло около 15 минут. На macOS или Linux:

```bash
ROBOTS_RERUN=1 jupyter execute --inplace --timeout=-1 cases/robots/robot_reference.ipynb
```

На Windows в командной строке cmd:

```bat
set ROBOTS_RERUN=1
jupyter execute --inplace --timeout=-1 cases/robots/robot_reference.ipynb
```

Для пошаговой работы откройте ноутбук в VS Code и выберите Python из созданного окружения как ядро. Чтобы повторить поиск при пошаговой работе, поставьте `RERUN = True` в начале ячейки запуска. Если поиск завершился ошибкой, смотрите таблицу статусов и лог этого запуска в папке результатов.

Если EPDE уже скачан в другое место, укажите путь к клону в переменной окружения `EPDE_ROOT`. Его коммит должен совпадать с указанным выше.

## Данные

Используется запись с 30 роботами из папки с данными роботов в репозитории EPDE. Она загружается вместе с клоном и здесь не дублируется. Загрузчик, оценка арены и признаки контактов тоже взяты оттуда с сохранением авторства. Условия самостоятельной публикации данных следует уточнять у авторов.

## Результаты

В папке результатов для каждого поиска лежат файл с найденным фронтом и настройками и полный лог. Там же сводные таблицы: статусы и длительности запусков, все модели и формы моделей с критериями, а также описание окружения контрольного запуска.
