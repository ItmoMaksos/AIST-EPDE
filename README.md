# AIST + EPDE: поиск скрытой динамики в эмпирических данных

Общий репозиторий проектов трека. Здесь лежат задание, разобранный пример и ваши работы.

**Тема.** Поиск и подготовка эмпирических данных для идентификации скрытых динамических систем эволюционными алгоритмами.

**Цель.** Найти реальные данные (физические, биологические, экономические или социальные процессы), для которых нет общепринятых дифференциальных уравнений или точной математической модели, и получить для них модель с помощью фреймворка EPDE.

Источник данных и тему вы выбираете сами. Один набор данных закрепляется за одним участником: кто первым внёс его в [таблицу](https://docs.google.com/spreadsheets/d/1zszSZDSWWLhcImijAwMiyROHS_Qr9ixOkQbmZbInxQ4/edit?usp=sharing), за тем он и остаётся.

## С чего начать

1. Прочитайте [задание](ASSIGNMENT.md): там требования, состав работы и критерии разбора.
2. Посмотрите [пример с роботами](cases/robots/robot_reference.ipynb). Он показывает путь от гипотезы и замены координат до своих токенов, фронта и проверки на новых данных. Это пример подхода, а не ещё один набор данных для выбора.
3. Если хотите запустить пример сами, следуйте [инструкции по установке](cases/robots/README.md).
4. Оформите работу по [шаблону проекта](templates/project_README.md).

Работа рассчитана на ноябрь, в конце месяца проходит внутренний отбор лучших работ на питчи. Подробности и критерии — [в задании](ASSIGNMENT.md#как-будет-разбираться-работа). Вопросы задавайте в общем чате.
